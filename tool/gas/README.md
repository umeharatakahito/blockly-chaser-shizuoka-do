# 提出をドライブに整理するスクリプト (Google Apps Script)

提出物を **u16@sangi.jp の Google ドライブ** に保存するためのスクリプトです。

- 作品部門: 参加者はログインせずに、`/works` の画面から 1GB までのファイルを提出できます。
  保存先は「U16作品部門 提出」フォルダ
- プログラム部門: `/entry` で受け付けたエントリーと .blch を、受け付けるたびに写します。
  保存先は「U16プログラム部門」フォルダ(エントリー台帳・提出プログラム台帳・「提出プログラム」フォルダ)

ファイル本体はブラウザからドライブへ直接送ります。このスクリプトは
「アップロード枠を作る」「届いたか確かめて台帳に書く」だけを行います。

## 1. スクリプトを作る (u16@sangi.jp で)

1. u16@sangi.jp でログインし、<https://script.google.com/> →「新しいプロジェクト」
2. プロジェクト名を「U16作品部門 提出」にする
3. `コード.gs` の中身を全部消し、`works-upload.gs` の中身を貼り付けて保存
4. 左の「プロジェクトの設定」(歯車) →「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
5. エディタに戻り、`appsscript.json` の中身を、このフォルダの `appsscript.json` で置き換えて保存

## 2. 初期設定を実行する

1. エディタ上部の関数の選択で `setup` を選び「実行」
2. 権限の確認が出るので u16@sangi.jp を選んで「許可」
3. 実行ログに次の3つが出る
   - 保存先フォルダ (ドライブの「U16作品部門 提出」)
   - 台帳 (同じフォルダのスプレッドシート。連絡先メールはここにだけ残ります)
   - **WORKS_GAS_SECRET に設定する合言葉** ← 後で使うので控える

## 3. ウェブアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 次を実行するユーザー: **自分 (u16@sangi.jp)**
3. アクセスできるユーザー: **全員**
   - 「全員」が選べない場合は、sangi.jp の Google Workspace 管理者に
     「Apps Script ウェブアプリを組織外に公開できるように」設定を変えてもらう必要があります
4. 「デプロイ」→ 表示された **ウェブアプリの URL** (`https://script.google.com/macros/s/.../exec`) を控える

## 4. Cloudflare に登録してデプロイする

リポジトリのフォルダで:

```bash
npx wrangler secret put WORKS_GAS_URL      # 3 の URL を貼る
npx wrangler secret put WORKS_GAS_SECRET   # 2 の合言葉を貼る
npm run deploy
```

参加者にだけ配る「受付コード」を付けたいときは、次も設定します(付けると画面に入力欄が出ます)。

```bash
npx wrangler secret put WORKS_PASSCODE
```

## 5. 確かめる

1. <https://blockly-chaser-shizuoka-do.blockly-chaser-shizuoka-do.workers.dev/works> を開き、
   小さな zip を提出する
2. ドライブの「U16作品部門 提出」にファイルが入り、台帳の状態が「完了」になっていること
3. 運営メニュー →「作品部門の提出」に出ていること

## スクリプトを新しくしたとき (例: プログラム部門の書き出しを足したとき)

1. `works-upload.gs` の中身で `コード.gs` を置き換えて保存
2. 関数 `setup` を選んで「実行」(新しいフォルダと台帳ができ、ログに出ます)
3. 「デプロイ」→「デプロイを管理」→ 鉛筆(編集) → バージョン「新バージョン」→「デプロイ」
   - URL は変わらないので、Cloudflare 側の登録はそのままでよい
4. 運営メニュー →「ドライブへの書き出し」→「ドライブへ書き出す」で、それまでの分をまとめて送る

## 注意

- スクリプトのコードを直したら「デプロイを管理」→ 編集 →「新バージョン」で更新する
  (新しいデプロイを作ると URL が変わるので、そのときは WORKS_GAS_URL も登録し直す)
- 保存先はドライブの容量を使います。u16@sangi.jp の空き容量を確認しておいてください
- 運営画面で削除しても一覧から消えるだけです。ドライブのファイルと台帳の行は手で消してください
- 大会後は台帳の連絡先メールを削除してください
